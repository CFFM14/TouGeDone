# 天下人苦头歌久矣 · TouGeDone

<img src="icons/icon128.png" width="72" height="72" alt="扩展图标">

面向头歌（EduCoder）的 Edge 扩展，集成选择题助手、DeepSeek 编程题助手和混合模式。当前版本 **2.9.0**，默认混合模式。

## 安装

1. 打开 [最新正式版](https://github.com/CFFM14/TouGeDone/releases/latest)，下载 `TouGeDone-v版本号.zip`，解压到固定目录。
2. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择包含 `manifest.json` 的目录。
4. 打开头歌答题页，点击扩展图标打开助手。

更新时覆盖原加载目录，在扩展页点击“重新加载”，再刷新答题页。沿用同一扩展时，已保存的密钥可继续使用。

## 使用

- **混合模式（默认）/编程题助手**：先点面板右下角“设置”，填写并保存 DeepSeek API Key，返回答题页后点击“开始”。
- **选择题助手**：无需配置密钥，选择模式后点击“开始”。
- 勾选“通过后自动下一关”后，只有明确通过才继续；不同模式按其范围处理或跳过题型。
- 拖动标题栏移动面板；同一标签页跨关记住位置。高级选项可调整主题、配色、布局和尝试参数。
- “停止”结束后续尝试并处理当前结果；“关闭”立即移除面板并终止后续自动操作。已发给平台的请求仍可能完成。

## 功能

- 单选逐题尝试；多选先清洗锁定，再进行最多4题的并行排除和命中拆分。
- 多选候选差量切换，共同选项不重复点击，已确认正确题锁定。
- 编程结合题干、已有源文件、公开评测反馈分析并修改允许的文件；模板只填指定区域。
- 自动保存确认、评测、失败反馈修复和冷却等待，模型固定为 `deepseek-flash`。
- 主面板与设置页统一外观，默认使用流程简化为“设置 → 保存 → 开始”。

API Key 在扩展设置中填写，保存在本机扩展存储，不随仓库发布；编程时相关题干、代码和公开反馈会发送给 DeepSeek，调用消耗账户余额。

## 开发与验证

本次回归环境为 Node.js 24。运行测试无需安装额外依赖：

```sh
npm test
```

测试覆盖选择题锁定/并行/差量点击、模板保护、保存确认、模式分流、跨关、停止关闭、密钥配置和面板交互。模拟回归与真实关卡验证的范围不同，不保证所有题型或所有关卡一次通过。

## GitHub 更新

从2.9.0开始，面板下方有“更新”入口。点击后自动打开设置页并检查GitHub正式版本，发现新版后可点击“下载新版”。

**解压安装版不能自动覆盖文件。** 下载后先停止任务，解压覆盖原加载目录，在 `edge://extensions` 重新加载，再刷新答题页。沿用原目录和同一个扩展，可以保留已保存的密钥。下载完成不代表已经安装。

旧的2.8.2及更早版本没有这个入口，需要先手动安装一次2.9.0。版本信息仅取自本仓库正式Release，不读取DeepSeek配置、不使用其Key、不接受任意下载地址，不下载执行远程脚本。

## 维护者发布新版

需要Node.js（测试）和Python 3（打包发布）。现有GitHub Git凭据需具有本仓库写权限，凭据仅在发布进程内存中使用，不写入包或日志。

1. 修改代码及版本记录，同步提高 `manifest.json` 和 `package.json` 的版本号。
2. 执行 `npm test`，然后提交并推送 `main`。
3. 执行 `npm run release`。脚本仅在工作区干净且HEAD与远程main一致时发布。

发布命令会生成白名单安装包、SHA-256文件和对应正式GitHub Release。同版本旧附件不覆盖，已有标签指向其他提交时停止；不要用相同版本替换已发布代码。只有推送代码而没有发布Release，插件不会将其视为新版。`npm run pack` 只在本地生成安装包。
